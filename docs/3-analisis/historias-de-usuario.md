# Historias de Usuario — ContractAI

ContractAI es una plataforma que usa **inteligencia artificial (IA)** para ayudar a freelancers, emprendedores y empresas a crear, analizar y gestionar contratos de forma rápida, segura y sin necesitar conocimientos legales.

**Proyecto:** ContractAI | **Empresa:** NexaOps  
**Docente:** Gloria Amparo Lora Patiño | **Uniremington · 2026**  
**Integrantes:** Juan Fernando Martínez Aguirre · Santiago García Patiño

> **¿Qué es una Historia de Usuario?**
> Es una frase corta que describe qué quiere hacer un tipo de usuario y qué beneficio obtiene.
> Sigue siempre el formato: **"Como [quién], quiero [qué], para [para qué]."**
