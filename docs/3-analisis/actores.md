# Actores del Sistema

| Actor | Rol en el sistema |
|-------|-------------------|
| **Freelancer** | Usuario independiente que genera contratos de servicios con clientes. Necesita plantillas rápidas y análisis de riesgo. |
| **PYME** | Empresa pequeña o mediana que gestiona múltiples contratos con proveedores y clientes. Requiere repositorio centralizado y roles. |
| **Usuario nuevo** | Persona que se registra por primera vez en la plataforma. |
| **Usuario registrado** | Persona autenticada con acceso a todas las funcionalidades del sistema. |
| **Administrador de plataforma** | Usuario con permisos elevados para gestionar plantillas del sistema, roles de usuario y estadísticas globales. |
| **Contraparte** | Tercero externo que recibe un enlace para revisar y firmar un contrato. No requiere cuenta en la plataforma. |
