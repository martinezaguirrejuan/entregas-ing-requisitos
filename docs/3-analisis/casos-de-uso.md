# Casos de Uso

| ID | Nombre | Actores | Descripción |
|----|--------|---------|-------------|
| CU-01 | Registrar cuenta | Empleado / Coordinador | El usuario crea una cuenta con nombre, correo y contraseña para acceder al sistema. |
| CU-02 | Iniciar sesión | Empleado / Coordinador | El usuario ingresa sus credenciales para autenticarse y acceder a las funcionalidades. |
| CU-03 | Generar contrato | Empleado / Coordinador | El usuario selecciona una plantilla, completa los datos y el sistema genera el contrato. |
| CU-04 | Analizar contrato existente | Empleado / Coordinador | El usuario pega el texto de un contrato y el sistema calcula el score de riesgo e identifica cláusulas problemáticas. |
| CU-05 | Ver historial de contratos | Empleado / Coordinador | El usuario consulta el listado de contratos generados y análisis realizados. |
| CU-06 | Cerrar sesión | Empleado / Coordinador | El usuario finaliza su sesión activa para proteger su cuenta. |
