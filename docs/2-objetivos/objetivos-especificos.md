# Objetivos Específicos

1. **Diseñar** un módulo de generación de contratos basado en plantillas predefinidas y en descripción libre mediante lenguaje natural, utilizando el modelo LLaMA 3.3 70B a través de la API de Groq.

2. **Implementar** un analizador de riesgo contractual que calcule un puntaje de 0 a 100 e identifique cláusulas problemáticas con su nivel de riesgo y sugerencias de mejora.

3. **Desarrollar** un sistema de firma digital que permita al usuario dibujar su firma, almacenarla en una biblioteca personal y agregarla a contratos con constancia de sello de tiempo, IP y hash SHA-256.

4. **Construir** un repositorio personal de contratos con funcionalidades de búsqueda, filtrado, versionamiento y gestión de vigencia con alertas de vencimiento.

5. **Establecer** un sistema de roles diferenciados (Freelancer, PYME, Administrador) con permisos y vistas adaptadas a cada perfil de usuario.

6. **Garantizar** la disponibilidad, seguridad y usabilidad del sistema mediante el cumplimiento de los requisitos no funcionales documentados (tiempo de respuesta, disponibilidad 99%, interfaz en español, contraseñas hasheadas).
